# Bundled fonts

The fonts in `core/ui/src/main/res/font/` are variable fonts from the Google Fonts
repository (github.com/google/fonts, `ofl/`), each under the SIL Open Font License 1.1.
Each font's licence file, with its copyright notice, is in this folder.

| File | Family | Licence |
|---|---|---|
| `roboto_flex.ttf` | Roboto Flex | `RobotoFlex-OFL.txt` |
| `inter.ttf` | Inter | `Inter-OFL.txt` |
| `manrope.ttf` | Manrope | `Manrope-OFL.txt` |
| `nunito.ttf` | Nunito | `Nunito-OFL.txt` |
| `lexend.ttf` | Lexend | `Lexend-OFL.txt` |
| `atkinson_hyperlegible_next.ttf` | Atkinson Hyperlegible Next | `AtkinsonHyperlegibleNext-OFL.txt` |
| `jetbrains_mono.ttf` | JetBrains Mono | `JetBrainsMono-OFL.txt` |

They are part of the app. PingMe never downloads fonts at runtime (CLAUDE.md rule 8).
