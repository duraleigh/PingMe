# PingMe clickable mockup

These are the source files of the interactive mockup built during the design phase:

- `Main.dc.html`: the Inbox screen
- `Chat.dc.html`: the Chat screen (a merged chat, with the service switcher)
- `canvas.json`: the canvas layout and the note explaining what is clickable

They are Design canvas artboards and need the canvas editor to render and to run.
The live, clickable version is at:

https://claude.ai/artifact/TjDSKPynFm4C3oCsbo6ENV

The mockup is a visual reference only. The written specification the build follows
is `docs/UI_DESIGN.md`, which includes everything the mockup shows plus the features
added afterwards. Where the two differ, `UI_DESIGN.md` wins.
